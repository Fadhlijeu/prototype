Komponen Glass Terintegrasi

Aplikasi ini merakit lebih dari 12 komponen Glass Dark Premium yang saling terhubung secara reaktif:

Floating Glass Dock Swirl Refraction Bottom Sheet Aurora Storage Card Frosted Folder Card 12-Hour Activity Telemetry Glass Buttons Collection Form Input Fields Glass Toggle Switch Glass Chat Input Bar Prompt Pills Quick Scroller AI Model Selector Card Thinking Effort Selector

Fitur Rekayasa & Arsitektur

  • Native Web Audio Synthesizer: Menghasilkan audio haptik procedural (pop, chime, tap) via AudioContext tanpa file MP3 eksternal.
  • Asymmetric Lighting: Simulasi arah cahaya fisik dari atas menggunakan border-top 0.35 dan border-bottom 0.06.
  • Canvas 2D Swirl Refraction: Shading refraksi matematis pada modal dialog pembuatan folder berkas.
  • Zero-Dependency Vanilla Architecture: 100% berjalan tanpa bundle build tool (Vite/Webpack) sehingga sangat cepat dan bebas konfigurasi.
